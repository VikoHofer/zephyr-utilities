MNIST runtime attribution
=========================

The Zephyr Utilities MNIST runtime template was adapted from the Apache-2.0 MNIST
shell demonstration supplied as a development reference. Its runtime source,
configuration and upload protocol are retained and maintained as a template
distributed with Zephyr Utilities. The original Apache-2.0 license is included
as ``LICENSE``; existing SPDX identifiers remain in the source files.

This source template contains no trained model, dataset images or captured device
results. Model and dataset assets are supplied separately by the managed MNIST
asset pack, which retains their identity and attribution.
